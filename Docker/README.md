# ProjectTemplate

Container image for the ProjectTemplate Console app.

## Image Tags

- `latest` - the current stable release, built from `main`.
- `develop` - the current prerelease, built from `develop`.
- `X.Y.Z` - immutable per-release tags.

## Usage

```sh
docker run --rm docker.io/ptr727/projecttemplate:latest
```
